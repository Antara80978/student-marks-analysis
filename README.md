# 📊 Student Marks Analysis

## Overview

Student Marks Analysis is a beginner-level Python data processing project
that analyzes student marks and calculates basic statistical measures.

## Objectives

The project calculates:

- Total marks
- Average marks
- Highest marks
- Lowest marks
- Number of students

## Dataset

A manually created Python list containing marks for 10 students is used
for the analysis.

## Technologies Used

- Python
- Jupyter Notebook

## Python Concepts Used

- Python Lists
- `len()`
- `sum()`
- `max()`
- `min()`
- Arithmetic operations
- Formatted output

## Results

| Metric | Result |
|---|---:|
| Number of Students | 10 |
| Total Marks | 819 |
| Average Marks | 81.90 |
| Highest Marks | 95 |
| Lowest Marks | 67 |

## Conclusion

This project demonstrates the use of Python for basic data processing
and statistical calculations. It provides a foundation for performing
more advanced analysis using libraries such as NumPy and Pandas.
